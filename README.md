# Dự Án Portfolio Cá Nhân - HTML & CSS

Chúc mừng bạn đã hoàn thành khóa học **HTML & CSS**! Đây là dự án tốt nghiệp cá nhân đã được đóng gói hoàn chỉnh, sẵn sàng xuất bản lên Internet qua **Netlify Drop**.

## 📁 Cấu Trúc Thư Mục Dự Án
```
portfolio-project/
├── index.html      # Trang chủ HTML5 chuẩn semantic
├── styles.css      # CSS3 Responsive layout (Flexbox, Grid, CSS Variables)
├── script.js      # JavaScript tương tác Menu & Dark Mode
├── README.md       # Tài liệu hướng dẫn dự án
└── NOP_BAI.md      # Mẫu nội dung nộp bài mẫu cho giảng viên
```

## 🚀 Hướng Dẫn Triển Khai Lên Internet Trong 60 Giây (Netlify Drop)

1. **Truy cập Netlify Drop:**
   - Mở trình duyệt web và truy cập địa chỉ: [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. **Kéo & Thả Thư Mục:**
   - Kéo toàn bộ thư mục `portfolio-project` và thả vào khung giao diện trên Netlify.
3. **Nhận Địa Chỉ URL:**
   - Sau vài giây, Netlify sẽ cấp cho bạn một đường link công khai dạng: `https://[ten-ngau-nhien].netlify.app`.
4. **Tùy Chỉnh Tên Miền (Không bắt buộc):**
   - Đăng ký tài khoản Netlify miễn phí để đổi tên miền thành ví dụ: `my-portfolio-2026.netlify.app`.
